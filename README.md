# 📸 Gallery Manager

Gallery Manager is a **browser-based image management system** built using **HTML, CSS, and JavaScript**.  
It allows users to create accounts, organize images into folders, upload photos, view them in fullscreen mode, and delete them easily.

The system stores **user data and folders using LocalStorage** and **images using IndexedDB**, making it a lightweight local gallery application that runs directly in the browser.

---

# 🚀 Features

✔ User Registration and Login system  
✔ Create and manage image folders  
✔ Upload multiple images to folders  
✔ View images in a responsive gallery layout  
✔ Fullscreen image viewer  
✔ Delete individual images  
✔ Delete folders along with their images  
✔ Browser-based storage using IndexedDB and LocalStorage  

---

# 🛠 Technologies Used

- **HTML5** – Structure of the application  
- **CSS3** – Styling and layout  
- **JavaScript (Vanilla JS)** – Application logic  
- **IndexedDB** – Storing uploaded images locally  
- **LocalStorage** – Saving users and folder information  

---

# ⚙ How It Works

1️⃣ User creates an account using the **Register page**  
2️⃣ Login with the created username and password  
3️⃣ Create folders to organize images  
4️⃣ Upload images into selected folders  
5️⃣ Images are saved locally using **IndexedDB**  
6️⃣ View images in the gallery or open them in **fullscreen mode**  
7️⃣ Delete images or entire folders when needed
